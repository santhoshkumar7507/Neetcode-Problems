## 📌 Overview

This repository contains my personal solutions to the algorithmic and data structure problems presented on [NeetCode](https://neetcode.io/). The goal of this project is to practice problem-solving skills, improve coding efficiency, and prepare for technical interviews.

All solutions are written in **Python**.

## 📁 Structure

The repository is organized by problem categories, matching the NeetCode roadmap. Currently, it includes:

- **[Arrays & Hashing](./Arrays%20&%20Hashing/)**
- **[Two Pointers](./Two%20Pointers/)**

*(More categories will be added as I progress through the roadmap.)*

## 🚀 How to Use

Each Python file corresponds to a specific problem. You can run any individual solution directly from your terminal:

```bash
python "Arrays & Hashing/1.py"
```
