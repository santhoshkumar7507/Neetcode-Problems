## 🚀 How to Run

You can easily run and test any of the solutions locally. Ensure you have Python 3 installed.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/santhoshkumar7507/NeetCode-Problems.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd NeetCode-Problems
   ```

3. **Run a specific file:**
   ```bash
   python "Arrays & Hashing/1.py"
   ```
